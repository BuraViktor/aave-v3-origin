# Security Policy

## Vulnerability Disclosure Policy

If you discover a security vulnerability within this project, please report it as soon as possible. We will respond to your report promptly and help you resolve the issue. 

You can send your report to [security@aave-v3-origin.com](mailto:security@aave-v3-origin.com). Please include as much detail as possible, such as how you discovered the vulnerability, what it affects, and steps to reproduce it if applicable.

## Security Reporting Guidelines

To make our response more efficient, please use the following guidelines when reporting security vulnerabilities:

1. **Identify the affected versions.**  Please include the version numbers of the software you are targeting.
2. **Describe the vulnerability.** Include details on how the vulnerability can be exploited and the impact of the attack.
3. **Provide a proof of concept.** If possible, provide steps to reproduce the vulnerability.
4. **Do not share the vulnerability publicly before we have had a chance to address it.** Publicly disclosing a vulnerability can make it more difficult for us to fix and for users to protect themselves.

Thank you for helping keep our project secure!
